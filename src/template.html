Set up

All you need is Docker with Docker ComposeExport every setting, frequency and config, and restore them anywhereIt runs on your hardware, so what you track stays with you
  • Download Docker Desktop from docker.com. On a Mac, pick Apple Silicon or Intel to match your Mac. On Linux, install Docker Engine instead.
  • Open Docker and wait until it says Engine running.
  • You don’t need a Docker account.
  • Keep Docker running whenever you use Sentinel.
  • Mac: press ⌘ + Space, type Terminal and press Return.
  • Linux: open Terminal from your apps.
  • Paste one command at a time, press Return, and wait for it to finish before the next.
Check Git is installed
git --version
  • On a Mac, if a box offers to install developer tools, click Install, then run the check again.
  • This downloads Sentinel into a folder called Sentinel.
  • It also makes Sentinel’s settings file, .env, inside that folder.
Download and set up
git clone https://github.com/barrygee/Sentinel.git
cd Sentinel
cp .env.example .env
  • A local SDR is one plugged into this computer by USB.
  • Skip this step if your SDRs are on another computer, or you’re just trying Sentinel.
1. Open the settings file
Mac
open -e .env
Linux
nano .env
2. Add one line, then save
Mac
SDR_MANAGER_LOCAL_NATIVE=1
Linux
COMPOSE_PROFILES=sdr-manager-local
3. Install the SDR programs, once
  • Mac: install Homebrew from brew.sh first.
  • Linux: these lines stop the SDR being taken for a TV tuner.
Mac
brew install librtlsdr uv
uv run --project backend sdr-manager-local install
Linux
echo 'blacklist dvb_usb_rtl28xxu' | sudo tee /etc/modprobe.d/blacklist-rtl-sdr.conf
sudo modprobe -r dvb_usb_rtl28xxu
  • Run this from the Sentinel folder.
  • After the first time, docker compose up -d starts it in seconds.
Start
docker compose up --build -d
  • On this computer, open the address below.
  • From a phone or another computer on your network, use this computer’s IP address instead, for example http://192.168.1.20:8080.
In your browser
http://localhost:8080
  • Open Settings with the gear at the bottom right.
  • App Settings: set your Machine Name and Location.
  • Space: pick a category, then press UPDATE TLE.
  • Sea: paste a free AISStream key.
  • Press APPLY CHANGES to save.
  • Air works straight away.
A local SDR
  • Plugged into this computer (step 4).
  • Open Settings › SDR › DEVICES.
  • It is listed under This machine. Press ADD.
A remote SDR on a Pi or another computer running SDR Manager
  • Open Settings › SDR › DEVICES and press + ADD A NEW SENTINEL HOST.
  • Enter its IP address, port 8000 and its console password.
  • Check the fingerprint matches, then press TRUST AND ADD.
  • Press ADD on each of its SDRs you want.
A remote SDR shared with rtl_tcp
  • On the computer with the SDR, run the line below.
  • Then press + ADD A REMOTE SDR DEVICE, enter a name, its IP address and port 1234, and press SAVE.
On the computer with the SDR
rtl_tcp -a 0.0.0.0 -p 1234
Then listen
  • Open SDR and pick the SDR at the top of the radio panel.
  • Settings › App Settings › CONFIGURATION › Export All Configuration saves everything to one folder.
  • That includes every setting, your SDR frequencies, groups and band plan, and this computer’s SDR Manager config.
  • To restore, or copy to another Sentinel, paste the settings into Application Config › EDIT and press APPLY CHANGES.
  • Frequencies and groups go back in through EDIT on Frequencies & Groups (JSON).
Stop Sentinel
docker compose down
Update to the latest version
git pull
docker compose up --build -d

  • From any browser on your network, open http://:8080.
  • It opens on Settings › SDR Manager.
  • Set a Console Password, a Machine Name and a Location.
  • Set each SDR to PUBLIC, with its stream on.
  • On your main Sentinel, open Settings › SDR › DEVICES.
  • Press + ADD A NEW SENTINEL HOST.
  • Enter this computer’s IP address, port 8000 and the console password.
  • Check the fingerprint matches, then press TRUST AND ADD.
  • Press ADD on each SDR you want to listen to.
  • SDR Manager Config (This Machine) holds the SDR names, ports, tuning and hotspot.
  • Press EXPORT to keep a copy.
  • To restore it, paste it back in with EDIT.
